Next Japan Innovation AIチャットボット設定（Gemini版）

実装済みファイル
- contact.html
- assets/js/chatbot.js
- chat-api.php

【重要】Gemini APIキーはGitHubへ絶対にコミットしないでください。
このリポジトリは公開設定です。

推奨設定
サーバー側の環境変数 GEMINI_API_KEY にAPIキーを設定してください。
chat-api.php は自動的にこの環境変数を読み込みます。

環境変数を設定できないレンタルサーバーの場合
公開ディレクトリの1階層上に次のファイルを作成できます。
ファイル名: nextji-gemini-key.php

内容:
<?php
return 'ここにGemini APIキー';

このファイルは公開ディレクトリ外に置き、GitHubへアップロードしないでください。

どうしても同一ディレクトリに置く場合
ファイル名: chat-api-config.php
内容:
<?php
return 'ここにGemini APIキー';

.gitignoreには chat-api-config.php と nextji-gemini-key.php を登録済みです。

AIモデル
- gemini-2.5-flash-lite
- Gemini Developer API generateContent

安全対策
- APIキーはブラウザへ送信しない
- 同一オリジンのみ許可
- 1メッセージ800文字まで
- IP単位の簡易レート制限
- 会話履歴は直近のみ送信
- メールアドレス・電話番号・カード番号らしき情報はGeminiへ送信しない
- 過去履歴内の明らかな個人情報はマスクしてから送信
- API障害・未設定時は従来の案内型チャットへ自動フォールバック
- 料金、納期、求人条件など未確定情報を推測しないよう指示済み

無料枠について
Gemini 2.5 Flash-Liteには無料枠があります。無料枠では入力内容がGoogleの製品改善に使用される場合があるため、個人情報はチャットへ入力せず、お問い合わせフォームへ直接入力する運用にしてください。

APIキー設定後、contact.htmlの右下チャットを開き、自由入力で「ホームページ制作について相談したい」などと入力してAI回答を確認してください。
